# Sonic Sandbox

Sonic Sandbox is an analog prototyping platform for developing and experimenting with guitar and bass effects.

The board provides the common circuitry and controls needed when prototyping a pedal, allowing the actual effect circuit to remain the focus. Audio input and output are handled through TRS jacks with high-quality op-amp buffers, providing a known and reliable interface to the circuit under test.

The board includes:

* **Buffered audio I/O** - TRS input and output with high-quality op-amp buffers
* **True bypass** - bypass the prototype circuit for direct A/B comparison
* **Mute control** - quickly silence the output while modifying or debugging a circuit
* **Potentiometers** - readily available controls for experimenting with circuit parameters
* **Switches** - configurable controls for testing different circuit configurations

Instead of rebuilding the same supporting circuitry for every experiment, Sonic Sandbox provides a reusable foundation for quickly breadboarding, testing, and iterating on new analog guitar and bass effects.
